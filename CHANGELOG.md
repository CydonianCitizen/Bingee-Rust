# Changelog

## 0.1.0-rc.1 — release candidate draft

Not published. Public distribution awaits the decisions in
[the release checklist](docs/release-checklist.md).

- Keep a local Movie and TV Library, with TMDB search and detailed title,
  season and episode information.
- Browse previously fetched information and posters offline.
- Track watched movies and episodes, personal ratings and watch history.
- See Statistics, Continue Watching, Up Next and Coming Soon on Home.
- Browse locally known episode dates in Calendar and release changes in Updates.
- Export backups and restore saved data with a safety backup created first.
- Optionally refresh metadata automatically while Bingee Desktop is open.
- Use desktop packages for Windows, macOS and Linux.
- RC polish clarifies first-run and backup guidance, makes Home rows consistent
  with other lists, and opens local details from History and saved Discover results.
