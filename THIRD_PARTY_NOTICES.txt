Bingee Desktop - third-party notices
====================================

Bingee Desktop is a local-first desktop media tracker built with Rust and
Slint. The license of Bingee Desktop itself is not decided yet. This file
lists the third-party software compiled into it and the terms it is used
under.

Several of these licenses require their full text to accompany binary
distributions. Bingee Desktop does not bundle those texts yet. Generate them
(for example with cargo-about) before any public distribution.


TMDB (The Movie Database)
-------------------------
This product uses the TMDB API but is not endorsed or certified by TMDB.
Discover searches https://www.themoviedb.org with the user's own API Read
Access Token, and Library posters are downloaded from TMDB's image server and
cached locally in the user's cache folder. The TMDB API is free for non-commercial use with attribution;
commercial use requires an agreement with TMDB.

ui/assets/tmdb-logo.svg is TMDB's official "alt short" blue logo, downloaded
unmodified from https://www.themoviedb.org/about/logos-attribution on
2026-09-14 (its SHA-256, 8e7b30f7...cd95f6c, matches the hash in TMDB's file
name). It is a TMDB trademark, used only to attribute TMDB as required by its
logo and attribution rules, and is compiled into the executable.


Benchmark posters (not shipped)
-------------------------------
benchmark/assets/posters/poster-001.jpg ... poster-100.jpg are synthetic
images generated by this project (examples/generate_posters.rs) for the
benchmark fixture. They are not derived from any real poster, contain no
third-party material, and are not part of the application package.


System components used but not shipped
--------------------------------------
Windows system libraries, the OpenGL driver, system fonts, and the Microsoft
Visual C++ runtime (VCRUNTIME140.dll, from the Visual C++ 2015-2022
Redistributable) are loaded from the target machine. They are not part of
the package.
