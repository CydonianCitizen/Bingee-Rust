# R12 — Home dashboard and Calendar

Home and Calendar read local SQLite only. Home shows Continue Watching, Up
Next, recent watch events, Coming Soon (today plus 14 days), and a Library
summary. Calendar shows a Monday-first month grid, day event counts, local
episode events, keyboard navigation, and a coverage warning. Series progress,
next-episode ordering, watch history, and coverage reuse R10 rules. No schema
or runtime dependency was added.

Tests cover empty and active Home, complete and partial series, a new episode
after completion, upcoming dates, recent history, empty months, multiple
events on one day, month and year boundaries, leap day, removed series,
coverage warnings, provider date-only semantics, and headless UI loading.
The statement-count test checks Home with zero and 20 series. The synthetic
1,000-title/17,550-episode release timing uses the existing R11 fixture.

The source has no automatic TMDB work in Home or Calendar. A pending Library
detail timer is gated while those pages are shown. Selecting an event opens
the stored series, season and episode where still available. Removed titles
retain history and cached detail. An absent provider episode remains a
graceful series-level fallback.

Status: PASS locally. Cross-platform CI awaits a user commit/push. See the session report in
`docs/run-reports/` for exact results and limitations.
