# R5 — Packaging and cross-platform sanity

This file records the brief as it was implemented (unattended session,
13 September 2026). The decision is in
`docs/adr/0005-portable-package-layout.md`. The evidence is in
`docs/measurements/R5-packaging-cross-platform/`.

**Status: PASS locally / cross-platform CI pending.** Every Windows criterion
passed and was verified locally. The CI workflow for Windows, Ubuntu and macOS
exists but has never run. This session could not commit or push:
`.claude/settings.json` denies `git commit`, `git push` and `gh`. macOS and
Linux are therefore source-audited only.

## Goal

Show that Bingee Rust builds and ships as a real desktop application, and that
nothing in it is accidentally Windows-only. Not a performance milestone: the
Slint renderer, features, cache budget, dependencies and workload are
unchanged.

## Implemented

1. **Package-root path resolution** (`src/main.rs`). The directory holding the
   executable is the root:
   - posters come from `<root>/assets/posters/`, falling back to the
     checkout's `benchmark/assets/posters/` only when that folder is absent
     (build-tree binaries);
   - the database is `<root>/data/bingee-spike.db`, and `data/` is created on
     launch.

   The working directory is never used. Only `std` is used; no new dependency.
   A unit test covers the fallback, packaged-assets priority, `data/` creation
   and the executable-directory root.
2. **Linux application ID.** `slint::set_xdg_app_id("bingee-desktop")` is
   called after the platform exists and before the window is shown. It sets
   the Wayland app_id and X11 WM_CLASS, and is a no-op on Windows and macOS.
3. **Windows console behavior**, unchanged and verified.
   `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` was
   already present. PE headers confirm the release executable uses the GUI
   subsystem and the debug executable the console subsystem.
4. **`scripts/package-windows.ps1`.** It builds `cargo build --release
   --locked`, recreates `dist/bingee-desktop-windows-x64/`, copies the
   executable and the 100 checksum-verified posters, creates `data/`, writes
   the notices (with the list of linked crates generated from `Cargo.lock`),
   the README and `SHA256SUMS.txt`, and prints the sizes.
5. **`scripts/smoke-windows-package.ps1`.** A non-interactive launch check from
   an unrelated working directory, plus a missing-poster run on a copy of the
   package that proves where posters are loaded from.
6. **`.github/workflows/cross-platform.yml`.** A matrix over `windows-latest`,
   `ubuntu-latest` and `macos-latest` that runs `cargo fmt --check`, `check`,
   `test`, `clippy --all-targets --all-features -D warnings` and
   `build --release`, all `--locked`. Ubuntu additionally installs
   `pkg-config` and `libfontconfig-dev`, the only build-time system library in
   the Linux graph. There is no `continue-on-error`.
7. **Licensing.** `THIRD_PARTY_NOTICES.txt` covers the Slint license
   assumption and its attribution condition, SQLite, the direct dependencies,
   the posters' provenance, and the system components that are not shipped.
8. **Docs.** README, ADR-0005, this file, and the R5 report.

## Not done / out of scope

An installer, code signing, zip or other archive, a macOS `.app` bundle or
Linux AppImage/Flatpak/`.desktop` file, an application icon, an About screen,
bundled full license texts, a static C runtime, per-user data directories,
and any performance or renderer change. No product features.
